# Award Bar Rubric (Webview Only)

**Scope:** Webview screens only (no impact on mobile/iOS).  
**Purpose:** Define objective criteria for an award‑level UI in 2026.

## Scoring Model
- Each category is scored **0–10**.
- A page is **award‑ready** when:
  - **Average score ≥ 9.0**, and
  - **No category below 8.5**.
- The suite is **award‑ready** when all core pages hit the bar.

## Categories
### 1) Information Hierarchy & Narrative (0–10)
**What “10” looks like**
- Primary intent is obvious within 3 seconds.
- Clear hierarchy: primary → secondary → tertiary.
- The page reads as a narrative, not a grid dump.
**Fail signals**
- Multiple “equal” focal points.
- Critical data lives in secondary visual treatment.

### 2) Data Clarity & Meaning (0–10)
**What “10” looks like**
- All charts are interpretable without guesswork.
- Targets, units, and legends are explicit.
- Users can answer “am I on track?” immediately.
**Fail signals**
- Decorative charts without scale or legend.
- Color used as meaning without labels.

### 3) Interaction Clarity & Affordances (0–10)
**What “10” looks like**
- Controls look like controls; stats look like stats.
- Active/hover/selected states are unmistakable.
- Navigation clearly communicates current location.
**Fail signals**
- Chips used for both filters and metrics.
- Dead UI: text that looks interactive but isn’t.

### 4) System Coherence & Consistency (0–10)
**What “10” looks like**
- Components behave and look the same across pages.
- Spacing, radius, elevation, and typography are consistent.
- Same data colors mean the same things everywhere.
**Fail signals**
- Component drift by page.
- Inconsistent spacing or data color mapping.

### 5) Visual Craft & Finish (0–10)
**What “10” looks like**
- Clean depth, no haze or accidental glow.
- Micro‑alignment is precise.
- Typography scale is intentional.
**Fail signals**
- Over‑reliance on blur/gradient.
- Inconsistent radii, padding, or weights.

### 6) Light/Dark Parity (0–10)
**What “10” looks like**
- Same hierarchy and meaning in both modes.
- Contrast and legibility meet accessibility norms.
- Light mode is not a “softened” version of dark.
**Fail signals**
- Light mode reduces data readability.
- Dark mode relies on glow for hierarchy.

## Evaluation Process
1. Score each page against all categories.
2. Note the top 3 blockers per page.
3. Re‑score after each major UI pass.
4. Final validation uses 2–3 external reviewers.

## Pages in Scope
- Dashboard / Today’s Snapshot (webview)
- Highlights / Coach (webview)
- Analytics / 30D (webview)

## Success Thresholds
- **Per‑page score:** ≥ 9.0 average; no category < 8.5
- **Suite score:** ≥ 9.2 overall
